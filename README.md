# «Журнал Московской Патриархии» как корпус текстов

Одностраничный сайт о пробном корпусном исследовании ЖМП на материале четырёх
номеров (1944, 1960, 1982, 2010). Исходник страницы — `index.qmd`, готовая
страница — `docs/index.html`.

## Состав репозитория

| Путь | Что лежит |
|---|---|
| `index.qmd` | текст страницы (Markdown для Quarto) |
| `_quarto.yml`, `styles.css` | настройки сборки и оформление |
| `img/` | графики (PNG), построенные `scripts/charts.py` |
| `data/` | сводные таблицы (CSV), по которым построены графики и таблицы |
| `meta/` | оглавления четырёх номеров: страница, рубрика, автор, заглавие |
| `scripts/` | код обработки: от PDF до сводных таблиц и графиков |
| `docs/` | собранная страница для GitHub Pages |
